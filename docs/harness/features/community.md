# Community Domain Guide

커뮤니티는 회원가입 없는 익명 사용자를 위한 기능이다.

## Features

- 게시글 CRUD
- 비밀번호 확인
- 댓글 CRUD
- 좋아요
- 조회수
- 태그

## Invariants

- 수정/삭제 권한은 현재 비밀번호 흐름을 따른다.
- 좋아요 레코드와 게시글의 집계 값이 일치해야 한다.
- 댓글 수는 실제 댓글 데이터와 일치해야 한다.
- 태그 JSON이 손상되었을 때 API 전체가 실패하지 않는 현재 fallback을 고려한다.

운영 보안 수준으로 확장할 경우 비밀번호 해시화가 필요하지만, 기능 수정과 인증체계 전면 교체를 혼동하지 않는다.
